鲸鱼内置环境音 · 素材来源与加工记录（第 60 轮）
==================================================

素材方针（2026-09-21 定）：环境音一律用素材库的真实录音——纯声频合成出来的背景音听感伤耳朵。
所以 `bgm/*.wav` 是真录音，不再是第 59 轮那段运行期合成的白噪声（合成器保留为兜底，见 BgmSources.synth）。

**全部素材都来自 OpenGameArt.org，作者本人上传、许可为 CC0（公共领域奉献）**：可随安装包分发，无署名义务。
下面仍记全来源与作者，便于日后核对或替换。

为什么一个 Freesound 的都没用：Freesound 上的声音虽然不少也是 CC0，但**不用 API key 只能拿到站点转码的
HQ 预览文件**（原件需登录下载），而 Freesound 的 FAQ/ToS 对"预览文件能否随作品再分发"没有任何表述
（2026-09-21 核对）。许可链上多这一层不确定没必要——OpenGameArt 的作者上传件是明确的 CC0。

--------------------------------------------------------------------------------
加工方式（生成脚本，可重跑，随开发环境维护）
--------------------------------------------------------------------------------
1. ffmpeg 解码 → 单声道 22050Hz float；
2. 取窗口（24 秒 / night 9.5 秒），**把"循环点之后该有的声音"按等功率叠到开头**做无缝循环
   —— 方向是关键：这样 out[0] 恰好是原素材里紧接 out[-1] 的那个采样，接缝处没有任何跳变
   （反过来把开头淡入到尾巴上，会留下一个硬跳变，听感就是每循环一次"啪"一下）；
3. 按 99.9 百分位归一化到 0.7，并压住绝对峰值不许削顶（避免"某一声门响"把整段拉小）；
4. 写成 16bit 单声道 WAV（无损：循环接缝不会被编码器填充搅坏）。

窗口起点是脚本自动挑的：`--pick seam` 挑接缝跳变最小的窗口；森林那档用 `--pick hf`
（在接缝合格的前提下挑 4kHz 以上能量最足的窗口——否则会挑到没有鸟叫的那一段）。
每档的客观指标（频谱重心 / 高频占比 / 短时起伏）与"接缝比"都打在脚本输出里；
桌面 `--smoke` 还会再逐档复核一遍（WAV 头、采样率、时长、响度、接缝比）。
