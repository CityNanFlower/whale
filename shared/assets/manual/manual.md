# 鲸鱼使用手册

> 这份手册随应用一起打包，**离线也能看**。手机端与桌面端共用同一份内容，界面位置不同的地方会分别写明。
> 手册按功能分节，点上方目录可以直接跳到对应小节。

## 一分钟上手

1. **填一把 Key**：进入「用户 → 外观与设置 → 模型与 API」（桌面端在第二栏点「模型与 API」），
   选一家供应商，把你**自己的 API Key** 粘进去，保存。
   - 支持：SiliconFlow / DeepSeek / 火山方舟 / 阿里通义千问 / Kimi / 智谱 / MiniMax / 腾讯云 / OpenAI / Gemini / 点点 等；
     任何 OpenAI 兼容的服务也可以**新增自定义供应商**。
   - Key 要去**供应商自己的控制台**申请（多数有免费额度，用超了要充值）。
   - **一家一份 Key**：换供应商不必重填，各自的 Key 分别存着。
2. **建一个角色**：进「角色卡 → 添加角色卡」，可以手写一张卡、从文件/PNG 卡导入、粘贴网址导入，
   也可以去「发现页」直接收一张现成的示例卡。
3. **开聊**：点角色卡开始对话。想换个开场白、加个世界观、配个音色，点角色卡上的「编辑」。

## 模型与 API

### 供应商与 Key

- 「模型与 API」分四段：**API 配置**（供应商与 Key）/ **对话模型** / **创作模型** / **生图模型**。
- 语音朗读与语音输入有**单独的凭据**，在「语音服务」页里填——有些供应商（如火山、腾讯）的语音需要
  另外开通、另外的 AppID / SecretId，与对话那把 Key 不是一回事。
- 没填 Key 的供应商，它的模型与参数会置灰，不会静默用错。

### 参数怎么选

- **对话模型**：决定回复质量与速度，也是花钱的地方。
- **创作模型**：AI 造角色卡、编形象提示词、写故事时使用，可以和对话模型分开配（便宜的快模型就够）。
- **生图模型**：生成头像 / 形象 / 聊天背景图。
- **思考强度**：给支持思考的模型分档。档位越高越"想得久"，也越慢越贵。
- **上下文长度**：历史裁剪的条数上限，回复很长或会话很久时调小能明显省钱。
- **temperature / maxTokens**：不确定就用默认值。

## 角色卡

### 新建与编辑

- **人设 / 世界观 / 开场白**：开场白可以写好**多条**，新会话会随机抽一条（多开局玩法）。
- **形象与背景**：形象用于角色卡展示；**背景图分手机端与桌面端两份**，同一张卡在两个设备上可以用不同的背景
  （只设一份也行，另一端会跟随；也可以明确"这一端不要背景"）。
- **角色专属音色**：默认关闭，打开后这个角色就用独立的声音（音色 / 语速 / 混音），不影响全局设置。
- **形态**：陪伴（单开场白）与多线（多开场白随机）两种玩法标签，用来在列表里区分。

### 导入与导出

- **导入**：「添加角色卡」里有三个入口——**文件导入**（JSON）/ **PNG 卡导入** / **从网址导入**（http/https，单文件 30MB 以内）。
- **导出**：可以把角色卡导出成 **JSON**（换设备迁移）、**纯文本**（粘给别人看）或**图片卡**（一张图发出去）。
- **PNG 卡**是通用格式：既能当图片发，也能被支持该格式的应用读取；鲸鱼导出的 PNG 卡可以直接导回来。
- 卡里带着的**新分类会自动进分类列表**（每个分类只补一次，你手动删掉过的分类不会被自动加回来）。

## 开聊

### 基本操作

- **发送**：手机点发送键；桌面 **Enter 发送、Shift+Enter 换行**。
- **多版本（重新生成）**：一条回复可以生成多个版本，左右滑动或点版本按钮切换，留下最满意的那个。
- **编辑 / 回溯 / 删除**：长按（桌面右键）消息气泡打开菜单，可以编辑内容、回到某一条重来、或只删这一条。
- **灵感回复**：让 AI 先给几条"接下来可以说什么"的建议，挑一条直接用。
- **本会话设定**：同一个角色可以有多种"你是谁"的设定，每个会话单独选。

### 记忆与前情提要

- **角色记忆**：把角色"应该长期记住的事"手动写进去，会一直参与后续对话；对话中也能让 AI 自己整理一份。
- **前情提要**：会话变长后，超出上下文长度的历史会被压缩成一段提要带进请求，长聊不至于"失忆"。

### 叙事风格

- 聊天页「更多」里有**叙事风格**：套餐（快速选一套）＋ 7 根独立的轴（如描写侧重、人称、节奏等）。
- 每一档下面直接写着**它会往提示词里加的那句话**，所见即所得；高级档可以进「叙事设置」全屏页逐轴微调。
- 「思考强度」也在这一栏，按当前会话临时调整。

## 语音朗读

- 两种引擎：
  - **系统朗读**：免费、离线（手机用系统 TTS，桌面用 Windows 语音），音色取决于系统里装了什么。
  - **供应商合成**：音色多、效果好，按字数计费（火山 / 腾讯 / 阿里 / MiniMax / 硅基流动 等）。
- **音色 / 语速 / 音高 / 混音**在「语音服务」页配置；朗读时括号里的动作描写会被跳过（可关）。
- **朗读与背景音乐可以同时进行**：AI 开口时音乐自动压低，说完恢复。
- 合成结果会**缓存**，重复听同一段不重复计费；「清除缓存」默认保留朗读缓存。
- 每个角色可以有自己的音色（见「角色卡」一节）。

## 语音输入

- 支持三家识别协议（硅基流动 / 阿里 / 火山极速版），也可以**不填 Key 走系统识别**。
- **Android**：首次使用要授予录音权限。
- **桌面（Windows）**：按住说话，松开后识别。系统识别需要 Windows 装了「语音识别」语言包；
  若录音失败，先检查 Windows 的**默认录音设备**是不是被设成了"扬声器 / 显示器"这类非麦克风设备。

## 背景音乐

- **内置九档**：雨声 / 海浪 / 篝火 / 森林 / 溪流 / 夜晚虫鸣（真实录音），加白噪声 / 粉噪声 / 布朗噪声。
- **音乐库**：上传自己的音乐（支持 mp3 / wav / m4a / aac / flac / ogg），可重命名、删除、试听。
  重命名只改应用内的显示名，不动文件本身。
- **会话级开关**：背景音乐**跟着会话走**——进聊天页才响、离开就停。
  每个会话可以选「跟随全局默认 / 本会话不播放 / 本会话自定义某首曲」。
- 入口：手机「用户 → 外观与设置 → 背景音乐」，桌面第二栏「背景音乐」；会话内的设置在**聊天页菜单 → 背景音乐**。

## 外观

- **主题**：浅色 / 深色 / 跟随系统。
- **字体与字号**：内置字体可选，也可以上传自己的字体文件；字号在设置里整体缩放。
- **聊天背景分端**：同一张角色卡可以给手机端、桌面端各配一张聊天背景（见「角色卡」一节）。

## 灵感创作（AI 造内容）

- 三种模式：**角色**（生成一张角色卡）/ **形象**（把描述变成角色形象图）/ **故事**（生成开场与剧情设定）。
- **模板**：内置多套模板，也可以自己存模板；模板只是把"该填什么"列出来，填完交给 AI。
- **生图**：尺寸、结果卡都在这一页，生成的图可以直接用在该角色上。
- 写了一半的提示词**会自动保存**：退出、切换页面甚至强杀进程后再打开，内容还在；只有点输入框旁的**叉号**才清掉。

## 发现页

- 精选的示例角色包：不用自己写卡，点一张卡**直接开始新会话**；一整包可以一键全收，已导入的卡会打标记。
- 清单与封面走"镜像优先"的通道，网络不通时退回上一次的清单。

## 数据、备份与缓存

- **数据都在本机**：没有服务器、没有账号云同步，角色卡与会话都是本地 JSON 文件。
- **数据备份**：「外观与设置 → 数据备份」可以把**全部角色与会话导出成一个 JSON**（图片会内嵌进去），
  换设备时导入即可恢复。**备份文件里不含 API Key**。
- **清除缓存**：只清可再生的东西（内置音源缓存、导出竖图、发现页缩略图、更新包、录音临时文件），
  **保留朗读缓存**，不会动你的角色、会话与聊天记录里的图片，也不会动「数据备份」导出的文件。
- **数据目录与缓存目录**：桌面端两个目录都可以自己指定，**设成同一个目录也没问题**——
  清理只认缓存目录里应用自己生成的那几个子目录，你的数据一个字节都不会碰。
- **多账号**：可以在「账号」里建多个本地账号，各自独立的角色卡与会话，互不干扰。
- **数据目录（桌面）**：可以在设置里改数据存放位置，改完点「重启以生效」；
  换了目录后下次启动会检查旧目录，只有可再生残留会静默清理，**还有你的数据就只提示不删**。

## 更新、安全与隐私

- **检查更新**在「版本与安全」页；更新包会做完整性校验（sha256），失败自动换源重试。
- 桌面端两种形态都支持应用内更新：便携包下载后点一下自动替换重启；装在系统目录的走安装器。
- **API Key 是加密保存的**：Android 走系统密钥库（密钥不可导出），桌面走 Windows 系统加密（DPAPI）。
  换了机器或系统账号，Key 需要重新填一次。
- **日志里不记 Key、不记正文**：只记长度与字数，方便排查问题又不泄露内容。
- 应用**只与你填的供应商通信**，没有第三方统计、没有广告。

## 常见问题

- **没有声音**：① 确认「语音服务」里填好了凭据并已开通、有余额；② 想免费可以先选"系统朗读"；
  ③ 桌面上再检查系统默认播放设备。
- **朗读报"合成失败"但我听到了声音**：这是分段合成里某一段失败后**回退系统语音**继续读的情形，
  已在近期版本修复（过滤无字片段 + 失败重试一次 + 回退写日志）。若仍出现，请把「版本与安全 → 异常记录」的内容发给我们。
- **想换手机 / 换电脑**：用「数据备份」导出 JSON，在新设备导入；API Key 需要在新设备重填一次。
- **自定义字体没有跟着恢复**：字体文件不进备份，换设备后需要重新上传一次。
- **会不会花很多钱**：应用本身免费也没有服务器；费用全部发生在你自己的供应商账号上——
  对话按 token、朗读按字数、生图按张。想省钱就调小上下文长度、少用高思考档、朗读用系统语音。
- **图片会不会丢**：正常不会。备份会把图片内嵌进 JSON；「清除缓存」也不会动你在用的图片。

## 手机端与桌面端的差异

- **布局**：手机是单页 + 底部导航；桌面是三栏（左栏图标 / 中间列表 / 右侧内容），窗口可自由缩放，
  支持拖拽导入图片与角色卡文件。
- **快捷键（桌面）**：Enter 发送、Shift+Enter 换行、Esc 返回、Ctrl+N 新建会话、Ctrl+K 搜索会话。
- **桌面专属**：托盘图标与右键菜单、开机自启、窗口大小与位置记忆。
- **手机专属**：分享到其它应用、保存图片到相册、PNG 卡分享。
- **两端数据互通**：手机导出的备份 JSON 可以直接导入桌面版，反过来也一样。
- 两个平台的**版本号独立编**，功能集保持对齐；「版本与安全」页会显示当前是什么平台的哪个版本。
