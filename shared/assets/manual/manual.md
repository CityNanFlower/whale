# 鲸鱼使用手册

> 这份手册随应用一起打包，**离线也能看**。手机端与桌面端共用同一份内容，界面位置不同的地方会分别写明。
> 手册按功能分节，点上方目录可以直接跳到对应小节。

## 一分钟上手

1. **填一把 Key**：进「用户 → AI 与语音 → 模型与 API」（桌面端在第二栏点「模型与 API」），
   选一家供应商，把你**自己的 API Key** 粘进去，点「⚡ 测试」能通就保存。
   - 支持：SiliconFlow / DeepSeek / 火山方舟 / 阿里通义千问 / Kimi / 智谱 / MiniMax / 腾讯云 / OpenAI / Gemini / 点点 等；
     任何 OpenAI 兼容的服务也可以**新增自定义供应商**（见「模型与 API」一节）。
   - Key 要去**供应商自己的控制台**申请（多数有免费额度，用超了要充值；鲸鱼本身不收费）。
   - **一家一份 Key**：换供应商不必重填，各自的 Key 分别存着。
2. **建一个角色**：进「角色卡 → 添加角色卡」，可以手写一张卡、从文件/PNG 卡导入、粘贴网址导入，
   也可以去「发现页」直接收一张现成的示例卡。
3. **开聊**：点角色卡开始对话。想换个开场白、加个世界观、配个音色，点角色卡上的「编辑」。
4. **挑个皮肤**（可选）：去「发现 → 皮肤中心」点一张卡就换；深浅模式与字体字号在「用户 → 外观」里。

## 模型与 API

> 这是全局配置里最容易迷路的一页：一共有**四个模型位**、**三层覆盖**。先花一分钟看完本节，之后就不会再问"我改的为什么没生效"。

### 四个模型位

「模型与 API」页从上到下分四段，每段管一类事：

- **API 配置**：供应商与 Key——所有模型都从这里取凭据。
- **对话模型**：正经聊天用，附带一整套对话参数（思考强度、温度、预算…），见下文「对话参数怎么调」。
- **创作模型**：AI 造内容用（生成角色卡 / 世界书 / 故事、整理记忆等）。可以和对话模型分开配——便宜的快模型就够。
- **生图模型**：生成头像 / 形象 / 聊天背景图用。
- **语音朗读与语音输入不在这一页**：它们有**单独的凭据**与页面（「语音服务」），有的供应商（如火山、腾讯）
  需要另外开通、用另外的 AppID / SecretId，与对话那把 Key 不是一回事。

### 供应商与 Key

- **怎么配**：进「API 配置」段 → 点「更换」选一家 → 把 Key 粘进去 → 点「⚡ 测试」，通了就保存。
- **一家一份 Key**：内置十几家供应商，各自的 Key 分开保存，切换不必重填。
- **没填 Key 的供应商**：它在列表里是置灰的，不会静默用错。
- **自定义供应商**：任何 **OpenAI 兼容**的服务都能接——把 Base URL（接口地址）与 Key 交给「新增自定义供应商」，
  模型名直接手填即可。列表里的家数会显示为「N 家已存」。
- **Key 是加密保存的**：Android 走系统密钥库、桌面走 Windows 系统加密（DPAPI）。
  **换机器或换系统账号需要重填**——卸载重装也会清掉；备份 JSON 里**不含 Key**。
- **Key 去哪申请**：各供应商自己的控制台；多数有免费额度。

### 在哪些地方换模型（三层覆盖）

"现在用什么模型"可以在三个层次上改，**越靠近当前的场合优先级越高**：

1. **全局默认**（就是本页这四段）——没被别的层覆盖时用它。
2. **场景级**（灵感创作、生图这类页面顶部的**模型胶囊**）：点开按供应商分组列模型。
   - 选「**本次使用**」＝只改这个场合（比如只让生图换到便宜模型），别处不动；
   - 选「**全局默认**」＝直接改设置页里那份，不必再绕回设置页；
   - 胶囊**高亮**＝这个场合设了覆盖；菜单里的「跟随全局默认」可以清掉。
   - 这里选的是**成对的家 ＋ 模型**：选了别家的模型，供应商一并切换。
3. **会话级**（聊天页「模型与思考强度」面板）：只影响当前这个会话，也可以**连同供应商一起换**——
   想拿另一家试试这一轮，不必动全局设置。

> 关系一句话：**会话 ＞ 场景 ＞ 全局**。改了发现"没生效"，先看是不是被上面一层覆盖着。

### 对话参数怎么调

- **思考强度**：给支持思考的模型分档（多数是「默认 / 关闭 / 深度」，各家档位不同）。开了思考回复更细，但也更慢更贵；
  **有些模型（如点点 dots3、Kimi K3）关不掉思考**，界面上照实显示。
  - 关键规则：**思考与正文共用同一份输出额度**。所以"设置值小于 8192 且当前会思考"时，实际发送会
    **自动抬到 8192**（否则推理把额度吃光、正文为空）。界面上的「当前实际发送」写的就是真实值——
    你的设置值会保留，切回不思考的模型/档位后自动恢复。
- **温度（Temperature）**：0~2，越高越发散；写剧情对话常用 **0.8~1.2**。个别供应商不支持这个参数，那里会置灰并说明原因。
- **内容拒答自动回落**（开 / 关）：模型因内容原因给了空回复或报错时，自动换更含蓄的写法重试一次，最多 2 级；
  回落过会在聊天页给一行提示。关掉＝只提示、不重试。
- **对话预算**三档（都在「对话模型」段里）：
  - **宽松**（默认）：按「单条回复总输出上限」发送；上下文超过 24000 字符时自动从最早的消息丢起。
  - **节省**：一键预设——关思考 ＋ 该模型允许的最低总输出档 ＋ 12000 字上下文（填完仍可逐项微调）。
  - **自定义**：三个旋钮自己配——单条回复总输出上限 / 上下文字符预算 / 携带历史条数（默认 40）。
- **全局补充系统提示词**（可选）：追加在每次对话系统提示词的最后（标记为【补充要求】），
  **对所有角色、所有会话生效**——适合写通用的说话风格与边界要求；想针对某个角色单独要求，写进角色卡的人设里更合适。
- **适配**：每段都有「适配」行，点开能看到这家供应商的接入能力（思考参数怎么传、支不支持温度、返回格式等）；
  显示「未适配」就代表不会瞎发参数、保持模型默认行为。

## 角色卡

### 新建与编辑

- **编辑页的走法**：手机上是分节长页（点某节标题跳到该节）；桌面端是**两段式**——左边一条分节导航、右边是内容，点左侧条目跳到对应一节。
- **人设 / 世界观 / 开场白**：开场白可以写好**多条**，新会话会随机抽一条（多开局玩法）。
- **形象与背景**：形象用于角色卡展示；**背景图分手机端与桌面端两份**，同一张卡在两个设备上可以用不同的背景
  （只设一份也行，另一端会跟随；也可以明确"这一端不要背景"）。背景图可以**裁一下**再存。
- **角色专属音色**：默认关闭，打开后这个角色就用独立的声音（音色 / 语速 / 混音），不影响全局设置。
- **形态**：陪伴（单开场白）与多线（多开场白随机）两种玩法标签，用来在列表里区分。
- **动过未保存时**：返回会先问一句「保存更改？」——「保存并退出」或「放弃更改」，不会悄悄丢。
- **开聊入口**：角色卡**长按直接开聊**；单击是看卡（双击的旧玩法已退役）。

### 导入与导出

- **导入**：「添加角色卡」里有三个入口——**文件导入**（JSON）/ **PNG 卡导入** / **从网址导入**（http/https，单文件 30MB 以内）。
- **导出**：可以把角色卡导出成 **JSON**（换设备迁移）、**纯文本**（粘给别人看）或**图片卡**（一张图发出去）。
- **PNG 卡**是通用格式：既能当图片发，也能被支持该格式的应用读取；鲸鱼导出的 PNG 卡可以直接导回来。
- 卡里带着的**新分类会自动进分类列表**（每个分类只补一次，你手动删掉过的分类不会被自动加回来）。
- **卡里带的字段不是全都用得上**：`系统提示词`目前只保存与导出、**不参与对话**；作者 / 版本 / 作者留言只做展示。
- **占位符只认 `{{char}}` / `{{user}}` / `<BOT>`**，别的写法原样保留（见「世界书」一节）。
- **导入工具类卡**时，卡的开场白会被当作「使用示例」填进输入框（按卡的类型约定判断，不做内容识别）。

## 世界书

- **是什么**：给角色配的资料库。每个条目写一段设定（地点、人物、历史、术语…）＋ 一组**关键词**；
  对话里提到这些关键词，这段设定才会被送进这一轮请求，没提到就不占上下文。
- **在哪管**：
  - **跟着角色**：角色卡编辑页的「世界书」页签——新建、让 AI 生成、导入、把一整本拆成条目。
  - **独立成书**：角色卡页的宝库段（角色｜世界书｜故事）。这里的书是账号级的，一本可以给多个角色引用；
    桌面端是「柜格 ＋ 名册」同屏排布。
  - 聊天页角色名旁的「‹」角色信息里能看到**本会话命中了哪些条目**——"为什么没起作用"先看这里。
- **关键词怎么定**：
  - **主关键词**：任一命中就激活（多个词之间是"或"）。
  - **副关键词**：打开「需要副关键词」后，还要再命中副关键词里的**任意一个**才算数（"与"的关系，只支持这一档）。
  - **常驻**：勾上就不看关键词、每轮都在（适合"必须一直记住"的设定）。
  - **扫描深度**：往回看几条消息里找关键词（默认 4 条）。调大更容易命中，也更容易翻出早已不相关的条目。
  - **匹配方式**：可选区分大小写、全词匹配、按正则解释关键词；正则写坏了会自动退回普通子串匹配，不会让整本书失效。
- **命中后插在哪**：条目按「位置」决定落进提示词的哪一段——
  **角色设定前 / 角色设定后 / 消息内 · 倒数第 N 条**（默认）。「消息内」会把条目以系统资料的身份插进最近几条对话中间，
  位置更靠后、模型更容易照着写；个别对消息顺序严格的服务商可能报错，遇到就把那条改成"设定前 / 设定后"。

> 「新条目默认用哪个位置」只是新建 / 生成 / 拆分出来时的初值，**已经建好的书与条目不会被改动**。

### 与通用世界书格式的差异

鲸鱼能读、也能写回通用的角色卡与世界书格式（SillyTavern 的 `character_book`）；**不认识的字段原样保留、导出时一字不改**，
所以卡在我们这里过一手不会掉设置。下面几项是**有意不做**的取舍，不是坏了：

- **按概率随机命中**（`probability`）：我们不做随机。同一句话有时记得、有时不记得，在角色扮演里更像故障而不是特性。
- **互斥分组**（`group` / `group_weight`）与副关键词的其它判定档（`selective_logic`）：只做"任一命中"这一档。
- **递归扫描**：命中集合只看最近几条消息，不会因为 A 条目提到了 B 的关键词就再激活 B（不滚雪球）。
- **书级 token 预算**：不做。要省上下文请用「扫描深度」和常驻条目的数量来控制。
- **没有「作者注释（Author's Note）」槽位**：词条位置选「作者注前 / 后」的，会并进「角色设定前 / 角色设定后」两档。
- **导入是「整本替换」**，不与现有条目合并（两份来源的条目编号都从 0 开始，合并后界面定位与命中会指到错的那条）。
- **老版 World Info 文件**（`entries` 写成 `uid → 条目` 的那种）**可以直接导入**，但导出统一写成新版格式；
  老版独有的字段不会丢，会写进词条一起带出去。

### 占位符

- 卡与词条正文里的 `{{char}}`、`<BOT>` 会替换成角色名，`{{user}}` 替换成「你」。
- **其它写法一律原样保留**（不做替换，也不会被吃掉）。

## 开聊

### 基本操作

- **发送**：手机点发送键；桌面 **Enter 发送、Shift+Enter 换行**。
- **多版本（重新生成）**：一条回复可以生成多个版本，左右滑动或点版本按钮切换，留下最满意的那个。
- **编辑 / 回溯 / 删除**：长按（桌面右键）消息气泡打开菜单，可以编辑内容、回到某一条重来、或只删这一条。
- **会话页的样子**：AI 动笔时有一排**跳动的点**（文案随皮肤换）；AI 气泡上方有**角色名**一行，**点头像**能看角色卡；
  头像没设图时显示角色名第一个字。
- **灵感回复**：让 AI 先给几条"接下来可以说什么"的建议，挑一条直接用。
- **本会话设定**：同一个角色可以有多种"你是谁"的设定，每个会话单独选。
- **输入栏**：手机空白时右侧是「麦克风 / 从相册选图 / ＋」，打了字换成「（）＋发送」；「（）」在光标处插一对括号
  （选中文字会把它包起来）。**打了字之后就不能再选图**了（那一格让给了「发送」），要带图请**先选好图再打字**。
  桌面输入栏是一排**纯图标按键**，悬停会显示说明。
- **＋ 互动面板**：从相册选图；「拍摄」暂未接入、是灰的（点了会说明，不会静默没反应）。
- **玩法形态**：每轮末尾的编号选项**只是文字、不能直接点**，要自己回复编号；玩法**不会改动你的模型温度设置**，
  想更稳或更活由你自己调。
- **开发者模式**：在「用户」页打开后，AI 气泡上会多一行**可折叠的「思考过程」**（模型返回了思考才显示；
  对开启后的新回复生效）——平时关着时界面上零痕迹。

### 记忆与前情提要

- **角色记忆**：把角色"应该长期记住的事"手动写进去，会一直参与后续对话；对话中也能让 AI 自己整理一份。
- **前情提要**：会话变长后，超出上下文长度的历史会被压缩成一段提要带进请求，长聊不至于"失忆"。

### 叙事风格

- 聊天页「更多」里有**叙事风格**：套餐（快速选一套）＋ 7 根独立的轴（如描写侧重、人称、节奏等）。
- 每一档下面直接写着**它会往提示词里加的那句话**，所见即所得；高级档可以进「叙事设置」全屏页逐轴微调。
- 「思考强度」也在这一栏，按当前会话临时调整。

### 聊天背景

- **入口**：聊天页「更多 → 聊天背景」；打开的是一个**弹窗**（与本页其它设置项同一形式）。
- **作用端**：背景**分手机端 / 桌面端**两张，弹窗里先选改哪一端；只设一端时另一端跟随。
- **能做什么**：选本地图片 / 让 AI 生成一张背景 / 把现有图**裁一下** / 调**暗化强度**（拖动即时预览）/
  把这张图**复制到另一端** / **移除背景图**（只影响当前这一端，需确认）。
- **当前背景来自哪**很直白地写在弹窗里：「本会话设置的图 / 继承自角色卡 / 未设置背景」等。

## 聊天记录

- **手机端**：是**编年长卷**——左侧一条时间刻度，按「今天 / 昨天 / 更早」分段；行尾「⋯」是会话菜单；
  **向左横滑**露出红底「删除」按钮，**点一下**才进确认（取消会自动滑回）。
- **桌面端**：第二栏是会话列表（标题带上总数、按日期刻度分段，每行副标题＝角色名 · 条数）；
  点一行，第三栏显示该会话的记录，右上角写着「N 条 · 相对时间」。
- **搜索**：桌面 **Ctrl+K** 直接搜会话；手机在聊天记录页顶部搜索。

## 语音朗读

- 两种引擎：
  - **系统朗读**：免费、离线（手机用系统 TTS，桌面用 Windows 语音），音色取决于系统里装了什么。
  - **供应商合成**：音色多、效果好，按字数计费（火山 / 腾讯 / 阿里 / MiniMax / 硅基流动 等）。
- **音色 / 语速 / 音高 / 混音**在「语音服务」页配置；改完可以**试听**——系统朗读与供应商合成两种都能试
  （供应商那路需要 Key 与余额）。朗读时括号里的动作描写会被跳过（可关）。
- **朗读与背景音乐可以同时进行**：AI 开口时音乐自动压低，说完恢复。
- 合成结果会**缓存**，重复听同一段不重复计费；「清除缓存」默认保留朗读缓存。
- 每个角色可以有自己的音色（见「角色卡」一节）。

## 语音输入

- 支持三家识别协议（硅基流动 / 阿里 / 火山极速版），也可以**不填 Key 走系统识别**。
- **Android**：首次使用要授予录音权限。
- **桌面（Windows）**：按住说话，松开后识别。系统识别需要 Windows 装了「语音识别」语言包；
  若录音失败，先检查 Windows 的**默认录音设备**是不是被设成了"扬声器 / 显示器"这类非麦克风设备。

## 背景音乐

- **内置九档**：雨声 / 海浪 / 篝火 / 森林 / 溪流 / 夜晚虫鸣（真实录音），加白噪声 / 粉噪声 / 布朗噪声。
- **音乐库**：上传自己的音乐（支持 mp3 / wav / m4a / aac / flac / ogg），可重命名、删除、试听。
  重命名只改应用内的显示名，不动文件本身。
- **会话级开关**：背景音乐**跟着会话走**——进聊天页才响、离开就停。
  每个会话可以选「跟随全局默认 / 本会话不播放 / 本会话自定义某首曲」。
- 入口：手机「用户 → AI 与语音 → 背景音乐」，桌面第二栏「背景音乐」；会话内的设置在**聊天页菜单 → 背景音乐**。

## 素材库

- **是什么**：AI 生成的图片与文字集中存放的地方（灵感创作产出的形象图、背景图、角色卡、世界书草稿都在这里），
  可以打标签筛选，按分类浏览。入口：手机「用户 → AI 与语音 → 素材库」，桌面第二栏「素材库」。
- **取用**：素材详情按**分类**给对应的动作——「形象/背景」可**存到相册**（桌面：存到导出目录）、
  「角色卡」可**存为角色卡**、「世界书」可**保存为新世界书**；图片素材顶部可直接**预览**，文字素材的正文**可编辑**，保存即生效。
- **删除**：手机**向左横滑**露出红底「删除」（点一下才删）；桌面在卡片上给删除按键 / 右击删除。
- **一键清空**：胶囊上按当前分类**清空**（有确认）；进入**选择模式**时不提供破坏性动作。

## 外观

- **皮肤**：内置多套——**简约**（默认，中性灰白＋蓝）、**潮汐**、**深海**（衬线）、**米白**、**手账**、**书信**、**暗房**。
  皮肤决定配色、圆角与装饰；**浅色 / 深色 / 跟随系统**在「用户 → 外观 → 主题」里，与皮肤自由组合。
- **皮肤中心**：在「发现页」里的**皮肤中心**看全部样张、**点卡即换**；「用户 → 皮肤中心」也有入口。
  带配套字体的皮肤在套用时**后台下载字体**，卡上状态行会写「字体下载中… / 字体下载失败 · 点按重试」——不假装已生效。
- **主题贴纸**：部分皮肤自带贴纸装饰（手账＝图钉、胶带、朱印；书信＝邮戳、火漆；暗房＝胶片条、片基标签），
  只落在页边与卡片角，单页最多三件，纯装饰不挡内容。
- **字体与字号**：「用户 → 外观 → 字体」里可以选内置字体族、**上传自己的字体文件**、整体缩放字号；
  皮肤自带的字体随皮肤走（见上）。
- **投稿皮肤**：皮肤中心里有「**去 GitHub 投稿**」——会打开预填好的投稿页面，把你自己的皮肤发给我们。

## 灵感创作（AI 造内容）

- **三种模式**：**角色**（生成一张角色卡）/ **形象**（把描述变成角色形象图）/ **故事**（生成开场与剧情设定）。
- **台面切换**：左上角在「**表单**」与「**产出**」两个台面之间切——表单是写提示词的地方，产出是看结果的地方，
  生成完成后会自动到产出这一面；结果**独立成台面**，不再挤在表单下面。
- **模型胶囊**：页面顶部有一枚模型胶囊（按当前模式对应「创作模型」或「生图模型」），点开可切「本次使用 / 全局默认」，
  见「模型与 API」一节。
- **模板**：内置多套模板，也可以自己存模板；模板只是把"该填什么"列出来，填完交给 AI。
- **生图**：尺寸、结果卡都在这一页，生成的图可以直接用在该角色上。
- 写了一半的提示词**会自动保存**：退出、切换页面甚至强杀进程后再打开，内容还在；只有点输入框旁的**叉号**才清掉。
- **老的自建模板没有形态**：模板改按四种形态之后，以前自己存的模板仍能用，只是套用时不会切形态。

## 发现页

- 精选的示例角色包：不用自己写卡，点一张卡**直接开始新会话**；一整包可以一键全收，已导入的卡会打标记。
- 卡片上有**包内张数角标**与**前几张卡的名片徽标**；空位（故事 / 模板）会写明「筹备中」，暂不可点。
- 侧边「**索引**」按主题 / 角色浏览；**皮肤轴**在下方——这就是皮肤中心。
- 清单与封面走"镜像优先"的通道，网络不通时退回上一次的清单；页面底部有三个状态点：
  在线 / 清单已缓存 / 清单拉取失败。

## 用量统计

- **在哪**：手机「用户 → 数据与存储 → 用量统计」，桌面第二栏「用量统计」。
- **记什么**：每一次请求**真实消耗的 token**——对话 / 生图 / 语音识别 / 语音合成四条链路都记；
  区间可选今天 / 近七天 / 近三十天 / 自定义。
- **怎么看**：柱状图（每小时发出的请求数）＋ 按模型**分色的堆叠图**（token 合计）＋长区间按真实日历排的**热力图**；
  **点柱子**弹出该时段的明细卡片。
- **下面两张卡**：小计卡（请求 / token / 生图 / 字符四格）与「按链路」卡（每条链路各多少次、多少 token）；
  再往下是明细列表，可按模型、链路、供应商筛选。
- **口径**：语音链路**按协议不计 token**（会写明"按协议不计"）；生图只计张数。用量只读本地台账，不花钱。

## 数据、备份与缓存

- **数据都在本机**：没有服务器、没有账号云同步，角色卡与会话都是本地 JSON 文件。
- **数据备份**（「用户 → 数据与存储 → 数据备份」）：可以把**全部角色与会话导出成一个 JSON**（图片会内嵌进去），
  换设备时导入即可恢复。**备份文件里不含 API Key**。
- **清除缓存**：只清可再生的东西（内置音源缓存、导出竖图、发现页缩略图、更新包、录音临时文件），
  **保留朗读缓存**，不会动你的角色、会话与聊天记录里的图片，也不会动「数据备份」导出的文件。
- **数据目录与缓存目录**：桌面端两个目录都可以自己指定，**设成同一个目录也没问题**——
  清理只认缓存目录里应用自己生成的那几个子目录，你的数据一个字节都不会碰。
- **多账号**：可以在「账号」里建多个本地账号，各自独立的角色卡与会话，互不干扰。
- **数据目录（桌面）**：可以在设置里改数据存放位置，改完点「重启以生效」；
  换了目录后下次启动会检查旧目录，只有可再生残留会静默清理，**还有你的数据就只提示不删**。

## 更新、安全与隐私

- **检查更新**在「版本与安全」页；更新包会做完整性校验（sha256），失败自动换源重试。
- 桌面端两种形态都支持应用内更新：便携包下载后点一下自动替换重启；装在系统目录的走安装器。
- **API Key 是加密保存的**：Android 走系统密钥库（密钥不可导出），桌面走 Windows 系统加密（DPAPI）。
  换了机器或系统账号，Key 需要重新填一次。
- **日志里不记 Key、不记正文**：只记长度与字数，方便排查问题又不泄露内容。
- 应用**只与你填的供应商通信**，没有第三方统计、没有广告。

## 常见问题

- **没有声音**：① 确认「语音服务」里填好了凭据并已开通、有余额；② 想免费可以先选"系统朗读"；
  ③ 桌面上再检查系统默认播放设备。
- **朗读报"合成失败"但我听到了声音**：这是分段合成里某一段失败后**回退系统语音**继续读的情形，
  已在近期版本修复（过滤无字片段 + 失败重试一次 + 回退写日志）。若仍出现，请把「版本与安全 → 异常记录」的内容发给我们。
- **换了皮肤字体没变**：带字体的皮肤要先**下载字体**（皮肤卡上会写状态）；下载失败点一下重试，或检查网络。
- **想换手机 / 换电脑**：用「数据备份」导出 JSON，在新设备导入；API Key 需要在新设备重填一次。
- **自定义字体没有跟着恢复**：字体文件不进备份，换设备后需要重新上传一次。
- **会不会花很多钱**：应用本身免费也没有服务器；费用全部发生在你自己的供应商账号上——
  对话按 token、朗读按字数、生图按张。想省钱就调小上下文长度、少用高思考档、朗读用系统语音。
- **哪些功能要另外开通付费**：语音合成与语音识别要在各自供应商控制台**单独开通并保证余额**才能用
  （朗读默认关闭）；**音色复刻的训练也是付费服务**；灵感创作里生成角色卡 / 形象 / 世界书 / 故事都是一次真实的
  AI 调用，按你配置的创作模型计费。想零成本就用"系统朗读"与"系统识别"。
- **图片会不会丢**：正常不会。备份会把图片内嵌进 JSON；「清除缓存」也不会动你在用的图片。

## 手机端与桌面端的差异

- **布局**：手机是单页 + 底部导航；桌面是三栏（左栏图标 / 中间列表 / 右侧内容），窗口可自由缩放，
  支持拖拽导入图片与角色卡文件。桌面**右栏可以用顶栏右上角的面板键收起 / 展开**。
- **快捷键（桌面）**：Enter 发送、Shift+Enter 换行、Esc 返回、Ctrl+N 新建会话、Ctrl+K 搜索会话。
- **弹窗与浮层**：同样的操作两端形式一致——确认类（删除、放弃更改等）手机从底部浮出、桌面居中弹出；
  补充信息的弹窗（管理分类、会话历史、聊天背景等）是居中卡片、右下角「关闭」。
- **长清单**：模型、音色预设、桌面工具面板等长清单到高度上限后会**在清单内滚动**，不会一路把页面撑长。
- **桌面专属**：托盘图标与右键菜单、开机自启、窗口大小与位置记忆。
  **托盘图标默认是"藏起来"的**——Windows 11 会把它放进任务栏的「显示隐藏的图标」浮层里。想让「检查更新」
  顺手可用，就到这个浮层里把它**拖到常显区**，或在桌面设置里打开「关闭窗口时缩小到托盘」。
- **手机专属**：分享到其它应用、保存图片到相册、PNG 卡分享。
- **两端数据互通**：手机导出的备份 JSON 可以直接导入桌面版，反过来也一样。
- 两个平台的**版本号独立编**，功能集保持对齐；「版本与安全」页会显示当前是什么平台的哪个版本。
